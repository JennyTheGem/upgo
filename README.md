# upgo

Structured goals for every project. Each project keeps a `goals.json` that agents only touch through the validating `upgo` CLI, a slim generated `goals.md` for agent context, and a local dashboard over every registered project.

## Use

```
upgo init                 # in a project folder: create goals.json, register it, install git + Claude hooks
upgo help                 # every command
upgo ui                   # dashboard on http://127.0.0.1:4141 (build it once with `npm run build`)
```

`upgo.cmd` (cmd/PowerShell) and `upgo` (Git Bash) are the PATH shims; both run `node cli.ts`. Node 22.18+ runs the `.ts` files directly.

## Pieces

- `src/core/`: zod schema, store (lock + atomic writes), mutations, ops, rules, checks, md renderer, importer.
- `cli.ts`: the CLI. `server.ts`: REST + SSE for the dashboard, 127.0.0.1 only.
- `web/`: React dashboard (Velora design system).
- `registry.json`: registered projects (`UPGO_REGISTRY` overrides the path, tests use it).
- `goals.schema.json`: generated by `npm run schema`, gives VS Code autocomplete.
- `skill/SKILL.md`: the agent skill, to be copied to `~/.claude/skills/upgo/`.

## Develop

```
npm test          # everything (vitest)
npm run typecheck
npm run lint
npm run build     # dashboard into web/dist
npm run dev       # dashboard dev server, with `upgo ui --no-open` running for the API
```
